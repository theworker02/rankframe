# rankframe

Rank structured JSON frame payloads without a heavyweight toolkit.

**Site:** https://theworker02.github.io/rankframe/

## Install / run

```bash
git clone https://github.com/theworker02/rankframe.git
cd rankframe
node src/cli.js
node --test
```
